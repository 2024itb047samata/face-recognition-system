# Face Recognition System 🎯

# 

# A real-time face recognition system built using Python, OpenCV, and the face\_recognition library. This project detects and recognizes human faces from images or live webcam feed.

# 

# 📌 Features

# 

# \* Real-time face detection

# \* Face recognition using trained images

# \* Works with webcam input

# \* Simple and easy-to-use interface

# 

# 🛠️ Tech Stack

# 

# \* Python

# \* OpenCV

# \* face\_recognition

# \* NumPy
